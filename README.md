# Laser Security System in Crop Protection from Wild Animals

An IoT and optical sensor-based non-lethal security barrier designed to detect and deter wild animal intrusion into agricultural land, mitigating human-wildlife conflict and protecting farm yield.

## 📌 Problem Statement
Farmers frequently suffer massive financial loss and emotional stress due to crop destruction by wild animals (boars, deer, monkeys, elephants). Traditional deterrence methods (scarecrows, electric fences, physical guarding) are either ineffective, expensive, dangerous, or harmful to wildlife. 

This project provides a **low-cost, non-lethal, automated laser-ultrasonic barrier** that continuously monitors field perimeters and activates targeted deterrents upon intrusion without harming animals.

---

## ⚙️ Hardware Components
- **Laser Emitter**: 532nm Green Laser (100mW)
- **Light Sensor**: LDR Photocell + 10kΩ resistor
- **Microcontroller**: NodeMCU (ESP8266) / Arduino Uno R3
- **Ultrasonic Alarm**: NE555 Timer IC ($R_1 = 20\text{ k}\Omega$, $R_2 = 2\text{ k}\Omega$ Potentiometer, $C_1 = 2\text{ nF}$)
- **Audio Output**: Piezo Speaker / Ultrasonic Transducer
- **Indicators**: Green LED (Safe), Red LED (Intrusion Alert)
